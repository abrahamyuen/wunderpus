# wunderpus
Free Mac app to remove AI metadata and C2PA Content Credentials from videos and photos before uploading, so file tags don’t trigger “Made with AI” / “AI info” labels on Instagram, Facebook, TikTok and YouTube. Right-click in Finder or drag &amp; drop. Strips EXIF, XMP and IPTC without re-encoding. Powered by ffmpeg + ExifTool.
